# لمسات مصطفى | متجر الكوزمتك

واجهة متجر عربية RTL لعرض منتجات كوزمتك لمسات مصطفى، مع كتالوج منتجات، تصفية وبحث، سلة مشتريات، طلب عبر واتساب، وروابط فيديوهات إنستغرام.

## التشغيل محلياً

```bash
pnpm install
pnpm run dev
```

## الفحص والبناء

```bash
pnpm run check
pnpm run build
```

## ملاحظات

- بيانات المنتجات والأسعار الحالية تجريبية ومهيأة للاستبدال بالبيانات الرسمية.
- الصور الحالية مرجعية من Unsplash، ويُنصح باستبدالها بصور المنتجات الأصلية قبل الإطلاق التجاري.
- رقم واتساب ورابط إنستغرام مضمّنان في واجهة الطلب والتواصل.
